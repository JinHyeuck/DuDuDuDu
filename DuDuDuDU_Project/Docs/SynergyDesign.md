# 시너지 (Synergy)

> 상태: **1단계 구현(2026-10-28).** 사용자와 대화로 정한 확정본. 수치는 사용자가 준 초안이다.
> 옛 초안(카드 3장 · 보드 상태 램프 · 전투 직전 세팅 화면 · 시너지 조각)은 폐기했다.
> 정본 표: 코드 `Assets/Scripts/Core/SynergyRules.cs` 의 `SynergyCatalog` (화면의 확률표와 실제 굴림이 같은 표를 읽는다).

## 한 줄 요약

계열(다이스 · 전투 · 행동 · 통합)마다 **고정 슬롯 1칸**. 슬롯은 **조건 1줄 + 효과 최대 3줄**이고,
조건 횟수 N 을 채우면 효과가 발동하고 카운터가 0 으로 돌아가 **계속 반복**된다.
옵션은 시너지 티켓으로 리롤한다.

## 규칙

| 항목 | 내용 |
|---|---|
| 슬롯 | 계열마다 1칸 고정. 계열마다 프리셋 4개, 장착 프리셋 1개. **리롤하기 전에는 비어 있다**(기본 옵션 없음, 빈 계열은 전투 HUD 에 안 뜬다) |
| 줄 | 조건 1 + 효과 1~3. 효과 2줄은 스테이지 20, 3줄은 스테이지 60 클리어 시 개방 |
| 수치 | 옵션마다 **Worst~Best** 범위에서 균등 랜덤. 조건은 N 이 작을수록 Best |
| 리롤 비용 | `(10 + 잠근 효과 수 × 10) × (조건 잠금 ? 2 : 1)`. 전부 잠그면 리롤 불가 |
| Best 보정 | 계열별로 쓴 티켓 누적. 확률 `min(누적 × 0.05%, 30%)`. 당첨되면 이번에 굴린 줄 중 **1줄만** Best, 누적 0. 프리셋끼리 공유 |
| 재화 | `PointType.SynergyTicket` — 핀볼 베이스 칸 경품(칸별 2/2/20/2/2) |
| 계열 개방 | 다이스 기본 / 전투 = 다이스계 리롤 30회 / 행동 = 누적 발동 2,000회 / 통합 = 무한의 탑 100층 |
| 켜지는 판 | 본편 스테이지만. 튜토리얼 · 무한의 탑은 끈다(유물과 같은 관례) |

### 설계 원칙 (사용자 결정)

- **효과는 반복돼도 괜찮아야 한다.** 한 판에 여러 번 터진다.
- **재화 지급은 전투계에만.** 행동계 조건이 SP·마석을 소모하므로, 같은 계열에서 돌려주면 스스로를 먹이는 고리가 된다.
- **통합계 효과로 일어난 발동은 어떤 카운트에도 넣지 않는다**(무한 루프 방지).
- **다이스 정체성 효과(슬로우·기절·중독·방어구 파괴)는 만들지 않는다.**
- **좋은 옵션과 나쁜 옵션이 섞인다.** 꽝도 있다(자리가 다 열렸을 때의 자리 오픈, 대상이 없는 처형 등).
- 단일 대상은 **맨 앞 몬스터**(벽에 가장 가까운 것).

## 조건 (Worst → Best)

| 계열 | 조건 | N |
|---|---|---|
| 다이스 | 특정 속성 다이스 N회 공격 / 특정 다이스 N회 공격 / 특수·킹 다이스 N회 공격 | 20 → 10 |
| 전투 | 몬스터 N마리 처치 | 20 → 8 |
| 전투 | 웨이브 N회 입장 / 보스 N회 처치 / 현상금 N마리 처치 | 3→1 / 2→1 / 3→1 |
| 전투 | 벽 N회 피격 | 10 → 4 |
| 행동 | SP N 소모 / 마석 N 소모 | 300→120 / 20→8 |
| 행동 | 머지 · 강화 · 소환 · 교환 N번 / 진화 N번 | 8→3 / 4→1 |
| 통합 | 다이스계 · 전투계 · 행동계 시너지 N번 발동 / 모든 시너지 N번 발동 | 6→2 / 8→3 |

"공격" 은 샷 단위다(범위·연쇄로 여러 마리를 쳐도 1회).

**피해 효과는 총알이다(2026-10-29).** 조건을 채우면 바로 때리지 않고 총알로 장전하고(단일·전체·공격력 % 모두, 5발 장전은 5발), 맞출 몬스터가 있을 때 **1초에 한 발**씩 나간다. 몬스터가 없을 때 발동해도 기회가 사라지지 않고 나타나는 즉시 나간다. 쌓아 둘 수 있는 건 200발, 공격력 % 는 쏘는 순간의 공격력으로 계산한다. 처치 효과도 총알이다 — 맞는 적(보스 제외, HP N% 미만)이 나타날 때까지 기다리고, 그동안 뒤에 선 다른 총알을 막지 않는다. 전체 피해는 맞는 몬스터마다 공격선이 나간다.

**고정 피해는 방어력과 받는 피해 증가, 보스 대미지 버프를 전부 건너뛰고 적힌 숫자 그대로 들어간다**(`Monster.TakeDamage(dmg, isFixed: true)`). 공격력 % 피해는 방어력을 받는다.

## 효과 (Worst → Best)

| 계열 | 효과 | 수치 |
|---|---|---|
| 다이스 | 맨 앞 적 고정 피해 / 맨 앞 적 공격력 % 피해 | 50→400 / 300→1200% |
| 다이스 | 맨 앞 적에게 고정 피해 N, 5발 장전(1초에 한 발) | 200 → 400 |
| 다이스 · 행동 | 적 전체 고정 피해(다이스만) / 적 전체 공격력 % 피해 | 20→150 / 100→500% |
| 다이스 | HP N% 미만 적 1마리 처치(보스 제외) | 5 → 20% |
| 다이스 · 통합 | 8초간 보스 대미지 +N% (5중첩) | 5 → 25% |
| 전투 | 자리 N개 오픈 / 벽 HP N% 회복 | 1→2 / 2→10% |
| 전투 | SP N / 보유 SP N% / 마석 N / 보유 마석 N% 지급 | 10→60 / 3→10% / 1→4 / 3→10% |
| 전투 | 5초간 벽 받는 피해 -N% | 10 → 40% |
| 행동 | 다음 소환 다이스 N성 / 보드의 무작위 다이스 1종 8초간 공격력 +N% | 2→3 / 10→50% |
| 통합 | 다이스계 · 전투계 · 행동계 시너지 N회 발동 / 다른 시너지 카운터 N% 채움 | 1→3 / 10→50% |
| 공통 | 8초간 공격력 / 특정 속성 공격력 / 특정 다이스 공격력 +N% (각각 중첩 없음 · 5중첩 판) | 5 → 30% |

**"% 피해" 는 공격력(장비 공격력 합)의 % 다.** 300~1200% 라는 수치가 현재 HP 기준으로는 성립하지 않아서 이렇게 읽었다.

버프는 같은 줄이 다시 터지면 중첩이 1 오르고 시간이 처음으로 돌아간다. 공격력 · 속성 · 다이스 버프는 더한 뒤 한 번 곱한다(유물 배수와 같은 층).

## 로비 가이드 (2026-10-29)

**첫 판에서 지기 전에는 시너지 입구 버튼 자체가 보이지도 눌리지도 않는다**(`UISynergyEntryButton` 이 `ContentUnlockManager.Defeated` 를 보고 CanvasGroup 으로 막는다, 2026-10-29). 이기고 나온 로비에는 가이드가 안 나온다.

**첫 판에서 진 뒤**(`ContentUnlockManager.Defeated`, 저장 `firstDefeated`) 다이스계 시너지가 열려 있고 **한 번도 굴려 본 적이 없으면**(`SynergyManager.GetRerolls(Dice) == 0`),
스테이지 보상 가이드 다음에 나온다(`LobbyUnlockDirector.SynergyGuideUntilDoneAsync`). 별도 저장은 없다 — 가이드를 끝까지 보면 리롤 횟수가 1 이 되어 다시 안 나온다.
**그때까지 스테이지 입장 버튼은 가려진다**(`ContentUnlockManager.IsStageEntryHeld`) — 창을 닫고 나가도 버튼이 돌아오지 않으므로 가이드를 되풀이해 끝까지 보게 한다.

1. 시너지 입구를 누르게 한다. 티켓이 10장보다 적으면 모자란 만큼 얹어 둔다(이미 있으면 더 주지 않는다).
2. 다이스계 카드의 **리롤** 버튼을 누르게 한다. 이 한 번은 무작위가 아니라 **고정 결과**다(`SynergyManager.BeginGuideRoll` → `SynergyRules.GuideReroll`):
   **노멀 속성 다이스 11회 공격 시 → 맨 앞 적에게 357 고정 피해 5발 장전**. 나머지 효과 줄은 비운다.
3. 나온 조건 · 효과를 실제 줄 문구로 읽어 주고, 탭하면 창을 닫는다.

창을 닫고 나가면 리롤이 안 일어나 가이드는 다음 진입에 처음부터 다시 나온다.

## 딜미터기

시너지 효과가 넣은 피해는 전투 화면 왼쪽 기여도 패널에 **"시너지" 한 줄**(보라 사각형 + 막대)로 다이스와 나란히 올라간다
(`DamageContributionTracker.RecordSynergy`, `SynergyRunManager.Hit`). 고정 피해는 초반엔 크지만 성장한 다이스 대비 막대가 짧아지는 것이 그대로 보이게 하려는 것이다.
처치 효과가 막대를 억 단위로 부풀리지 않게 **몬스터 남은 체력까지만** 센다. 탑은 시너지를 켜지 않아 결과 화면에는 안 나온다.

## 화면

- **로비**: 무한의 탑 입구 같은 버튼 하나(확정 콘텐츠가 아니라 탭에 넣지 않는다). 리롤 화면은 계열 4패널, 패널마다 프리셋 1~4 탭(누르면 장착), 조건 · 효과 줄마다 잠금, BEST 확률 `x.xx% / 30%` 과 누적 게이지, 리롤 버튼과 비용, 오른쪽 위 확률표.
- **전투 HUD**: 화면 오른쪽 세로 1줄. 원 안에 `n/N` 과 진행 링. 버프가 걸리면 원 아래에 종류별 합산(`공격 +63%`), 끝나면 글자와 배경을 끈다. 단일 타격은 대상까지 직선, 통합계가 다른 계열을 움직이면 곡선. 원을 누르면 조건 · 효과 · 중첩 · 남은 시간 상세. 안 열린 계열은 숨긴다.
