# 인게임 첫 튜토리얼

> 상태: **구현됨.** 코드는 `Assets/Scripts/Tutorial/`. 아래 "남은 결정" 은 기본값으로 구현돼 있다.
> 대상: 클라 첫 오픈 시 타이틀에서 곧장 들어가는 튜토리얼 전용 판 1회.

## 구조

| 파일 | 역할 |
|---|---|
| `TutorialProgressManager` | 루트 서비스. 완료 플래그(세이브)와 **다음 전투가 튜토리얼인지**의 예약. 탑의 `ConsumePendingRun` 과 같은 모양 |
| `TutorialRunManager` | 배틀 스코프의 순수 객체(탑·되돌리기와 같은 자리). 이 판이 튜토리얼인지, 그리고 랜덤을 덮을 대본(소환 6회·머지 결과 1회) |
| `TutorialStage` | 판 수치와 대본. `StageDatabase` 에 넣지 않는다 — 스테이지 진행도·별·소탕이 이 판을 세면 안 된다 |
| `TutorialDirector` | 단계를 순서대로 끈다(UniTask). 조건은 새 이벤트 없이 **이미 보이는 상태**(웨이브 상태·보드·SP·창 열림)를 기다린다 |
| `UITutorialOverlay` | 딤드(구멍 둘레 네 장)·손가락·말풍선. `Create()` + `OJ/개발/튜토리얼/UI 프리팹 굽기` |
| `OJ.Core.TutorialRules` | 소환 비용 합계, 건너뛰기 판정. 헤드리스 테스트 대상 |

**진입:** `TitleSceneController` 가 완료 플래그를 보고 로비 대신 전투로 보낸다. 전투의
`GameManager.InitializeStage` 가 예약을 한 번 꺼내 `InitializeTutorial` 로 간다.
개발 중에는 **DEV 치트 → 모드 → "인게임 튜토리얼 시작"** 또는 **Shift+F3** 이 완료한 세이브에서도 튜토리얼 판을 연다(완료 플래그는 건드리지 않는다).

**이미 본편을 한 세이브는 건너뛴다.** 완료 플래그는 튜토리얼보다 늦게 생긴 필드라,
스테이지 기록이 있거나 2스테이지 이상 열린 세이브는 플래그가 없어도 마친 것으로 본다(`TutorialRules.ShouldSkip`).

## 가이드 종류

| 종류 | 입력 | 진행 |
|---|---|---|
| **Dim** (딤드) | 구멍 안만 입력 허용. 나머지는 차단 | 완료 조건 충족 시 다음 단계 |
| **Finger** (손가락) | 전부 허용. 대상에 손가락만 | 완료 조건 또는 웨이브 시작 시 다음 단계 |
| **Talk** (말풍선) | 화면 전체가 탭을 받는다 | 탭 1회 |
| **Wait** | 가이드 없음 | 게임 상태 대기 |

구멍은 마스크가 아니라 **구멍 둘레 사각형 네 장**이다 — 구멍 자리에 이 창의 그래픽이 없으므로 클릭이 아래 버튼에 그대로 닿는다.
대상이 여럿이면 그 합집합이 구멍이고(머지 두 칸), 대상이 움직이므로(상세 패널은 다이스를 따라다닌다) 매 프레임 다시 잰다.

## 단계

웨이브는 **넷**이다. 마지막(보스) 웨이브에는 현상금이 안 나오므로(`BountyFormula.CanSpawnOnWave`)
"상위 현상금을 걸고 웨이브 실행" 에 자기 웨이브가 하나 있어야 한다.

| 단계 | 가이드 | 완료 조건 |
|---|---|---|
| **1웨이브 전** | | |
| IntroGoal | Talk | 탭 — "몬스터가 벽까지 오면 져요" |
| Summon | Dim 소환 버튼 | 대본 6회 소진 + SP < 비용 |
| Merge | Dim 노멀 두 칸 | 2성 번개가 보드에 생김 |
| StartWave1 | Dim 시작 버튼 | 웨이브 진입 |
| **1웨이브** | | |
| Wave1 | Wait | 관리 단계 복귀 |
| Wave1Reward | Talk | 탭 — "웨이브를 막으면 SP 를 받아요" |
| **2웨이브 전: 현상금** | | |
| BountyOpen | Dim 현상금 띠 | 선택 창 열림 |
| BountySelect | Dim 1단계 칸 | 1단계 선택 + 창 닫힘 |
| StartWave2 | Dim 시작 버튼 (SP 남긴 채) | 웨이브 진입 |
| **2웨이브: 되돌리기** | | |
| Wave2Crisis | Wait | 일반 몬스터 3마리 등장 |
| RewindTalk | Talk (`timeScale = 0`) | 탭 — "SP 를 하나도 안 쓰고 시작했어요" |
| Rewind | Dim 되돌리기 버튼 | 확인 창 열림 |
| RewindConfirm | Dim "되돌릴게요" | 확인 창 닫힘 → 되감기 후 관리 단계 |

| BountyHint | Finger 현상금 띠 | 창 열고 닫음 또는 웨이브 시작. 1단계를 잡으면 선택이 **저절로 2단계로 올라가므로** "골라라" 가 아니라 "올라갔다" 를 알린다 |

**지면 처음부터.** 어느 단계에서든 벽이 무너지면 "다시 해 봐요" 를 띄우고 판을 다시 연다.
단계는 세이브에 쓰지 않는다 — 판 도중 앱이 죽어도 다음 실행에서 처음부터다.

## 튜토리얼 판에서 덮는 것

| 대상 | 평소 | 튜토리얼 |
|---|---|---|
| 첫 소환 6회 | 랜덤 종류·랜덤 칸 | 노멀(9) · 노멀(10) · 노멀(5) · 불(8) · 얼음(11) · 독(6) — `TutorialStage.OpeningSummons` |
| 머지 결과 1회 | 랜덤 | 번개 |
| 그 뒤 소환·머지 | — | 평소대로 (대본이 바닥나면 평소 규칙) |
| 유물 | 소환 별·쌍둥이·비용 상승 건너뛰기·머지 보험·시작 SP·선제 배치·웨이브 클리어 | **전부 끔.** SP 가 "정확히 6회" 로 계산돼 있어 하나라도 끼면 첫 단계가 안 풀린다 |
| 시작 SP | 스테이지 값 | 첫 6회 소환 비용 합계 (`TutorialRules.SummonCostSum`) |
| 웨이브 클리어 SP | 스테이지 값 | 되돌린 뒤 3회 소환 비용 합계 |
| 되돌리기 | 판당 무료 1회 | 그대로. 튜토리얼에서 그 1회를 쓴다 (판이 끝나면 의미 없는 값) |
| 마석 | 웨이브당 +1 | EvolveGift 에서 진화 비용까지 **맞춘다**(더 있으면 깎지 않는다) |
| 나가기(정지) 버튼 | 있음 | 감춤 |
| 웨이브 골드 미리보기 · 결과창 · 스테이지 기록 · 클리어 보상 | 있음 | 없음. 이 판의 보상은 진화로 만든 Time 다이스다 |

**진화 성급 조건(4성)은 낮추지 않는다.** 판에서만 다른 규칙을 가르치면 일반 판에서 버그로 오해한다.
그래서 4성은 **지급**하고, 말풍선으로 "4성이 되면 변신할 수 있어요" 라는 실제 규칙을 알린다.

**속성강화는 이 튜토리얼에서 뺐다.** 진화와 같은 마석을 써서 한 판에 둘 다 가르치면 길고 수지가 꼬인다.

## 수치

`TutorialStage.Build` — 4웨이브, 웨이브당 8마리, 벽 100, 기본 HP 5(성장식은 1스테이지와 같은 계수), 보스 배율 6.
**플레이로 맞춘 값이 아니다.** 아래 셋을 실제로 눌러 보고 조정할 것.

- Wave2Retry 에서 1단계 현상금을 잡아야 한다(못 잡으면 BountyHint 가 건너뛰어질 뿐 막히지는 않는다).
- StartWave3 이후는 비강제라 아무것도 안 해도 이겨야 한다.
- 보스 웨이브 딜미터기 1위가 Time 이면 "변신해서 이겼다" 가 선다.

## 남은 결정 (기본값으로 구현돼 있음)

1. **되돌리기 남은 횟수 표시** — 버튼의 "되돌리기 1" 을 그대로 둔다. 따로 설명하지 않는다.
2. **딜미터기 안내** — 정지 없는 4초 말풍선으로 넣었다. 빼려면 `DamageMeterTip` 블록을 지운다.
3. **스킵 버튼** — 없다.
4. **튜토리얼 판 보상** — Time 다이스 하나. 스태미나는 타이틀에서 바로 들어오므로 쓰지 않는다.
5. **손가락 아트** — 아직 없어 Unity 내장 원·화살표로 자리를 잡았다. 아트가 오면 `TutorialUIPrefabBaker` 의 스프라이트 두 장만 바꾼다.

## 확정

- **변신 대상은 번개 → Time.** 머지 단계의 2성 번개와 계통이 이어진다.
- **Time 은 튜토리얼 보상으로 영구 해금한다.** `DiceUnlockDatabase.tutorialReward` 를 Time 하나가 갖는다.
  지급은 EvolveGift 에서 `DiceOwnershipManager.GrantFromContent` 로 한다(이미 보유면 가격만큼 환급).
  `TryEvolve` 가 대상 보유를 보므로 진화 **전에** 줘야 한다.
- **스테이지 14 는 KingThunder(신화석 다이스)가 받는다.** 탑 140층에서 옮겼다. **탑 140층 해금 자리는 비었다.**
