# 컨텐츠 해금

> 상태: **구현됨.** 코드는 `Assets/Scripts/ContentUnlock/`, 규칙은 `OJ.Core.ContentUnlockRules`.
> 정본 수치: `Assets/ScriptableObject/ContentUnlockDatabase.asset` (없으면 `ContentUnlockRules.BuildDefaults`).
> 순서 합의: 2026-10-13, 개정 2026-10-20(킹 썬더 3스테이지 해금 흐름), **개정 2026-10-24(1스테이지 시험 모드: 다이스·장비를 웨이브로 연다)**.

인게임 튜토리얼(Docs/IngameTutorialSteps.md)이 전투 시스템(소환·머지·현상금·되돌리기·속성강화·진화)을
전부 가르치므로, 해금 대상은 **로비 컨텐츠뿐**이다.

## 알리는 방법 3단계

| 방식 | 하는 것 | 언제 쓰나 |
|---|---|---|
| **Guide** | 해금 연출 → 손가락으로 입구를 **실제로 누르게** 하고 → 열린 화면 위에서 한 마디 | 안 하면 성장이 막히는 것, 화면이 복잡해 혼자 못 쓰는 것 |
| **Announce** | 입구가 튀어나오고(0→1.3→1) 딤드로 그 자리만 연 채 "무엇이 열렸다" 를 말한다 | 있는 줄 몰라 놓칠 것 |
| **Quiet** | 입구만 나타난다. 알림은 입구 자신의 레드닷 | "받기" 버튼 하나뿐인 것 |

원칙:
1. **가이드는 하나가 끝나면 바로 이어서 다음을 건다**(한 방문에 최대 2개, 그 이상은 다음 방문). 대기열 한 판은 가이드에서 끊기고,
   다이스·장비처럼 **탭으로 들어가는 가이드는 홈을 거치지 않고** 이어진다(상세 창을 닫아 하단 탭이 보인다). 그 밖의 가이드(탑·핀볼·상점…)는
   화면이 하단 탭을 가릴 수 있어 유저가 **홈 탭으로 돌아오면**(`LobbyLayoutController.CurrentTab`) 이어서 나온다.
   그래서 같은 클리어 안에서는 **연출을 가이드보다 표에서 앞에** 둔다.
2. **가이드를 마치면 스테이지 입장을 약하게 이끈다**(`StageEntryNudgeAsync`) — 딤드·탭 대기 없이 입장 버튼에 손가락만. 누르거나 홈을 떠나면 거둔다.
3. **결제 상품은 가이드하지 않는다.** 연출까지만.
4. **받기를 쓰기보다 먼저 연다** (고기 축제 → 소탕).

## 순서표 (2026-10-24 개정)

**웨이브로 여는 것(1스테이지 시험 모드).** `ContentUnlockDefinition.requiredWave` 가 0 보다 크면 **1스테이지의 그 웨이브를 깨면** 열린다
(`requiredClear` 는 그대로 1 — 스테이지를 통째로 깨도 열린다). 다이스는 **5웨이브**, 장비는 **10웨이브**.
세이브에 새로 저장하는 것은 없다(웨이브 기록은 `StageProgressManager` 가 이미 든다).

## 이전 순서표 (2026-10-20)

킹 썬더(신화 다이스)를 **3스테이지에서** 열어 유저가 신화 다이스의 힘을 빨리 체감하게 하는 흐름에 맞춘 표다.
3스테이지를 깨면 → 아랫줄이 바로 봉인되고(`TowerGateRules`, 오프셋 3) → 무한의 탑이 열려 → 탑 1층에서 킹 썬더를 장착해 깬다.

| 클리어 | 컨텐츠 | 방식 | 비고 |
|---|---|---|---|
| 0 (튜토리얼 직후) | 고기 축제 | Guide | **튜토리얼 직후는 이것 하나뿐.** 가이드가 뜰 때 고기를 한 세트(30개) **채워 두고**(`IdleRewardManager.EnsureMeatSets`) 받게 한 뒤 스테이지 입장을 이끈다 |
| 0 | 스테이지 보상 | Quiet | |
| 0 | 별의 축제 | Quiet | |
| 1스테이지 **5웨이브** | 다이스 | Guide | 노멀 다이스를 **3레벨까지** 올리게 하고(재화가 모자라면 미리 채워 둔다) 3레벨 마일스톤(최종 대미지 +10%) 줄을 짚어 "레벨마다 효과가 열린다 = 전략" 을 보여 준다 |
| 1스테이지 **10웨이브** | 장비 | Guide | |
| 1 (클리어) | 방치 보상 | Announce | |
| 2 | 핀볼 | Guide | |
| 3 | 퀘스트 | Announce | 미션은 전부 열어 둔다(숨기지 않는다) |
| 3 | 무한의 탑 | Guide | 3스테이지 클리어 직후 봉인 연출 → 탑 1층 |
| 4 | 소탕 | Guide | |
| 4 | 멤버십 | Quiet | 결제 상품 |
| 4 | 특별한 7일 | Quiet | |
| 5 | 상점 (보석 뽑기) | Guide | |
| 5 | 시즌 패스 | Quiet | 결제 상품 |
| 6 | 유물 | Guide | |

원칙:
1. **가이드는 연달아 뜨지 않는다.** 대기열은 가이드에서 끊기고, 남은 것은 유저가 가이드로 연 화면을 닫고
   **홈 탭으로 돌아왔을 때**(`LobbyLayoutController.CurrentTab`) 이어서 나온다(예전에는 다음 로비 진입까지 안 나왔다).
   그래서 같은 클리어 안에서는 **연출을 가이드보다 표에서 앞에** 둔다.
2. **결제 상품은 가이드하지 않는다.** 연출까지만(이번 개정에서는 Quiet).
3. **받기를 쓰기보다 먼저 연다** (고기 축제 0클리어 → 소탕 4클리어).

### 킹 썬더 흐름 (2026-10-20 구현)

| 단계 | 하는 것 | 코드 |
|---|---|---|
| 3스테이지 클리어 | **클리어 즉시** 킹 썬더 지급. 이미 보유면 환급이 클리어 보상에 붙는다 | `GameManager.ClearStage` → `StageRewardManager.GrantStageClearDice` |
| 보상 창 마지막 칸 수령 | 이미 보유면 지급·환급 없이 해금 연출만 보여 준다(환급 이중 지급 방지). 이 기능 이전 세이브처럼 미보유면 여기서 지급 | `StageRewardManager.TryClaim` |
| 로비 복귀 | 아랫줄 봉인 연출 → 퀘스트 연출 → 탑 가이드 | `TowerSealDirector`, `LobbyUnlockDirector` |
| 탑 가이드 | 탑 입구 → (설명) → **도전 버튼** → 편성 화면에서 **킹 썬더 칸을 눌러 장착** → 전투 시작. 추천 편성이 킹 썬더를 이미 끼워 놓았으면 빼 두고 유저가 직접 누르게 한다. 장착까지 보면 기록(출발은 씬이 바뀌어 기록 못 함) | `LobbyUnlockDirector.TowerLoadoutGuideAsync` |
| 탑 1층 첫 클리어 | 골드 + **신화석 10개** (`PointType.MythicStone`, `TowerFormula.FirstFloorMythicStone`) | `TowerRunManager.BuildClearRewards` |
| 1층 클리어 뒤 첫 로비 | 연출이 남지 않은 진입에서 다이스 탭을 가리키고 "신화석으로 킹 썬더를 강화" 안내 1회(`SaveState.Tower.KingUpgradeGuideDone`) | `LobbyUnlockDirector.KingUpgradeGuideAsync` |

킹 다이스 강화 안내는 **다이스 탭을 열게 하고 말풍선 한 번**이다. 강화 버튼을 직접 누르게 하는 단계 가이드는 아직 아니다.

**아직 안 한 것(후속):** 4스테이지 킹 썬더 유도(머지로 나오는 처음 두 3성이 썬더 — 구현됨, Docs/StageBalance.md. 마석 수급은 건드리지 않는다),
강화 버튼까지 누르게 하는 킹 다이스 강화 단계 가이드, 에디터에서 신규 세이브로 눌러 본 확인.

## 구조

| 파일 | 역할 |
|---|---|
| `OJ.Core.ContentUnlockRules` | 열림·보임·대기열·옛 세이브 채우기·표 검사·기본표. 헤드리스 테스트 대상 |
| `ContentUnlockDatabase` (SO) | 표를 들기만 한다. `StaticResource.ContentUnlockDatabase` |
| `ContentUnlockManager` | 루트 서비스. **연출을 봤는가**만 저장한다. 열림은 매번 `StageProgressManager.GetLastClearedStageIndex` 로 계산 |
| `LobbyContentGate` | 로비 입구 컴포넌트를 찾아 숨기고(`SetActive`), 하단 탭은 잠근다(흐림 + 자물쇠). `LobbySceneController.Awake` 가 코드로 붙인다 |
| `LobbyUnlockDirector` | 로비 `Start` 에서 대기열을 돈다. 화면은 튜토리얼의 `UITutorialOverlay` 를 그대로 쓴다 |

**열린 것과 보이는 것은 다르다.** Announce/Guide 는 열려도 연출을 끝까지 보기 전에는 입구가 숨는다 —
연출이 입구를 튀어나오게 하는데, 이미 보이면 무엇이 새로 생겼는지 알 수 없다. 가이드 도중에 앱을 끄면
기록이 안 남아 다음 진입에 처음부터 다시 나온다.

**잠긴 탭을 누르면** 탭을 넘기지 않고 "N스테이지를 클리어하면 열려요"(웨이브로 여는 것은 "1스테이지 N웨이브를 클리어하면 열려요") 알림 창(`UIConfirmDialog`, 버튼 하나)을 띄운다.

**특별한 7일 자동 팝업**은 연출이 남은 진입에서는 쉰다(소비하지 않으므로 다음 진입에 뜬다).
숨은 입구는 `Start` 가 안 돌아 자동 팝업도 안 뜬다.

## 세이브

`SaveState.ContentUnlock` — `initialized`, `announced`(ContentId 이름, 오름차순).

- **이 기능보다 먼저 생긴 세이브**(`initialized` 없음)는 이미 열린 것을 본 것으로 채운다 —
  안 그러면 10스테이지를 깬 사람에게 연출 열 개가 쏟아진다. 단 **한 판도 안 깬 세이브는 채우지 않는다**
  (튜토리얼만 마친 신규 유저라 다이스 가이드를 받아야 한다).
- 채우기는 표(SO)가 필요해 `ReadFrom` 이 아니라 **처음 물을 때** 한다. 그 전에 저장이 오면
  `initialized=false` 를 그대로 다시 쓴다 — `SaveService` 의 왕복 검사가 읽은 것과 쓴 것을 문자열로 대조한다.
- `ContentId` 이름을 바꾸면 그 연출이 이미 본 사람에게 다시 뜬다.
