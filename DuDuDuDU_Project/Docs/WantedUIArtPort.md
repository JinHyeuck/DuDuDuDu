# 현상금 UI · 경고 띠 — 아트 시안 적용 기록

2026-10-01. 현상금 띠·선택 창을 시안으로 바꾸고, 보스·현상금 등장 경고 띠(연출 포함)를 새로 붙였다.
옛 현상금 알림(`UIBountyCallout`)은 경고 띠로 대체되어 지웠다.

## 연출 (`UIBattleWarning`)

트위닝 라이브러리가 없으므로 경과 시간 하나로 모든 값을 계산한다. **실제 시간**(배속·일시정지 무관).

| 시각(초) | 무엇 |
|---|---|
| 0 ~ 0.18 | 띠가 세로로 펼쳐진다 |
| 계속 | 줄무늬가 위는 왼쪽, 아래는 오른쪽으로 흐른다 · 삼각형이 0.18초마다 두 장을 번갈아 깜빡인다 |
| 0.08 ~ 0.38 | 마름모+해골이 튀어나온다(살짝 넘쳤다 돌아옴) |
| 0.16 ~ 0.38 | WARNING! 이 크게 찍혀 들어와 박히고, 이후 맥박친다(보스만) |
| 0.26 ~ 0.52 | 문구가 튀어나온다 |
| 1.6 ~ 1.9 | 전체가 흐려지며 사라진다 |

레이캐스트를 전부 꺼 두어 떠 있는 동안에도 보드를 누를 수 있다. 관리 단계로 넘어가거나 판이 끝나면 즉시 거둔다.

## 결정표

| 항목 | 적용 | 근거·상태 |
|---|---|---|
| 카드의 금화 가격(1,000~5,000) | **실제 보상**을 [재화 아이콘] 수량으로 | 현상금에 비용이 없다. 시안의 금화는 자리 표시로 판단 · **추정** |
| 카드 이름 | 데이터 이름(하급 듀라한 …) | 시안의 "듀라한(1단계)" 는 데이터에 없다 · 확정 |
| 카드의 체력 | 표시 안 함 (띠에는 선택된 것의 HP·보상 표시) | 시안에 자리 없음 · **미확인** |
| 선택된 카드 | 노란 테두리 | 시안에 표시 없음 · **추정** |
| 잠긴 카드 | 흐리게 + "앞 등급을 먼저" | 기존 규칙 유지, 시안에 없음 · **추정** |
| 선택 창 바깥 | 어둡게 하지 않음, 누르면 닫힘 | 시안에 막 없음 · 확정 |
| 빨간 X | 막대 둘로 그림 | 킷에 X 아이콘이 없다 · **아이콘이 오면 교체** |
| 보스 경고 | 본편 보스 웨이브의 보스 등장 순간 | 탑 보스층에는 안 띄움 · **미확인** |

## 사람이 할 일

- `Wanted_Bg` 9슬라이스 테두리 다듬기(위 대략값). Sprite Editor 에서 고치면 다시 굽지 않아도 반영된다.
- 빨간 X 아이콘 스프라이트가 생기면 `UIBountyUIFactory.CreateCross` 를 스프라이트로 바꾼다.

## 확인한 것

- 헤드리스 EditMode 테스트 3631 통과, `verify-all` PASS, UI 프리팹 검사 4종 0건.
- 굽은 프리팹 에디터 캡처를 시안과 나란히 대조 — 띠·판·카드·경고 띠·삼각형·해골·WARNING! 위치 일치.
- 플레이(TitleScene → 로비)에서 경고 띠 보스·현상금을 차례로 재생 — 테마 전환, 연출, 스스로 닫힘 확인.
- **전투 안의 띠·선택 창 바인딩은 플레이로 누르지 않았다** — 전투 입장이 실제 세이브의 고기를 쓴다.

## 함께 한 것

- `DialogCatalog.asset` 에서 가리키는 프리팹이 없는 항목 6개를 지웠다 — 지운 `UIBountyCallout` 1개와,
  이전 굽기로 fileID 가 바뀌어 이미 죽어 있던 5개(상점·핀볼 페이지 옛 판 4, 없는 프리팹 1). 살아 있는 항목은 그대로다.
