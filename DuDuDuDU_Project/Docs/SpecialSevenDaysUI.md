# 특별한 7일 — 구현 기록

> **상태: 적용 완료 (2026-10-06).** TitleScene 부터 재생해 확인 — 로비 진입 시 창 자동 노출(하루 1회),
> 미구매 1일차 "보상 받기" 회색 + 자물쇠, 3일차에 구입 → 1~3일차 일괄 수령(유료젬 +800 = 300 + 500),
> 4일차 줄 "보상 받기" 개별 수령, 7칸을 다 받으면 로비 입구가 내려감.

기획 정본: `Docs/BMDesign.md` 6장(상품·회수 구조), `Docs/ShopPackageDesign.md` 2.2·2.3·4장(화면).
레퍼런스: 사용자 스샷(출석 리턴 패키지).
