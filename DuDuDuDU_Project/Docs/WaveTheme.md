# 웨이브 테마 (1스테이지 시험)

> 상태: **구현됨(2026-10-27, 1스테이지만).** 코드 `OJ.Core.WaveTheme` · `OJ.Hunting.WaveThemeFlow` · `WaveThemeUi` · `WaveThemeLayout`, 스위치 `StageData.waveTheme`.
> 측정과 수치는 `Docs/StageBalance.md` "1스테이지 30웨이브 · 웨이브 테마".

10웨이브가 한 바퀴이고 같은 패턴을 30웨이브까지 되풀이한다. 웨이브가 끝나면 **유저가 보상을 고른 뒤** 다음 웨이브가 열린다.

| 웨이브(한 바퀴 안) | 전투 | 끝난 뒤 |
|---|---|---|
| 1 · 2 · 4 · 7 · 8 | 물량전 | **이벤트**(영혼 보너스 · 행운 주사위 · 다이스 선물 · 벽 회복 · 보스전 — 아래 "이벤트" 표). 영혼 보너스 창은 닫아도 고를 때까지 다시 뜬다 |
| 3 · 6 · 9 | 물량전 | **현상금 도전할래요?** (도전 / 패스). 도전하면 기존 현상금 선택 창 → 기존 경고 연출 → 잡을 때까지 → 다음 웨이브 |
| 5 | 물량전 | **자리 +4칸 / 영혼 보너스** 중 하나. **광고를 보면 둘 다**(스테이지당 2번) |
| 10 | **보스 한 마리, 60초 안에** | **자리 +4칸 그리고 영혼 보너스** (고르는 것이 아니라 둘 다) |

- 보스를 60초 안에 못 잡으면 벽이 무너진 것으로 친다(되돌리기 제안 포함). 제한 시간은 게임 시간이라 배속을 따른다.
- 광고: `IRewardedAdService` 가 있으면 그것을 쓰고, 없으면(에디터) 바로 성공으로 친다. 광고 버튼은 실제 서비스가 없고 에디터도 아니면 안 뜬다.
- 자리 +4: `UIBoard.GrantFreeSlots` — 잠긴 자리를 앞에서부터 SP 없이 연다(탑에 막힌 칸은 건드리지 않는다).

## 주의
- 화면 요소는 전부 코드로 만든다(씬·프리팹 YAML 을 손대지 않는다). 중첩 캔버스는 **오브젝트의 레이어로 카메라에 걸러지므로** 만든 오브젝트의 레이어를 부모와 맞춘다(`WaveThemeUi.Rect`).
- 한 줄 칸 수는 `UIBoard.ConfigureColumns(8)`(이름과 달리 `rows` 가 한 줄의 칸 수다).
- 옛 영혼 보너스(처치 수가 차면 저금통 버튼)는 이 스테이지에서 쓰지 않는다(`SoulBonusManager.OfferNow` 로 웨이브 끝마다 제안).
- 값은 사람이 해 보고 정한다: 보스 체력 배수 `bossWaveHpFactors`(1 / 3.5 / 1.5), 중반 램프 `hpRampMultiplier`(3.8), 다이스 쿨타임 `BalanceProfile.CooldownMultiplier`(0.6).

## 이벤트 (2026-10-27) — 영혼 보너스만 나오던 자리를 나눴다

이벤트 자리(한 바퀴의 1·2·4·7·8웨이브 뒤)는 **영혼 보너스 · 행운 주사위 · 다이스 선물 · 벽 회복 · 보스전** 다섯 종이 한 바퀴에 한 번씩 나온다.
배치는 바퀴마다 다르다(`WaveTheme.After` 의 표, 셋째 바퀴부터는 첫 바퀴로 돌아온다). 고르는 창은 전부 코드로 만든 `UIChoicePopup` 이고, 흐름은 `WaveThemeFlow` 에 있다.

| 이벤트 | 1~10웨이브 | 11~20웨이브 | 고르는 것 |
|---|---|---|---|
| 영혼 보너스 | 1 | 12 | 기존 창(SP / 마석) |
| 행운 주사위 | 2 | 17 | **굴려서 마석 5~15개**(평균 약 10) / **50 SP 받기** |
| 다이스 선물 | 4 | 11 | 정해진 다이스 둘 중 하나를 보드에 받는다 — 1바퀴 파이어 2성 / 썬더 2성, 2바퀴 타임 / 허리케인(특수는 1성). 빈 칸이 없으면 50 SP |
| 벽 회복 | 7 | 14 | **벽 체력 10% 회복** / **50 SP 받기** |
| 보스전 | 8 | 18 | **마석 10개 받고 지나가기** / **30초 안에 보스를 잡고 마석 20개**(못 잡으면 없음 — 벽이 닳아도 선택의 몫) |

- **행운 주사위**: SP 를 따로 내지 않는다. 50 SP 를 받는 대신 굴리는 쪽을 고르는 선택이다. 확률표는 `LuckyDiceRules.EventChance`(5 → 5%, 10 → 14%, 15 → 4% … 합 100). 굴림 연출은 기존 `UILuckyDiceResultPopup`.
- **보스전**: 보스는 현상금 몸(체력·모습)을 빌린다 — 1바퀴 2등급, 2바퀴 3등급(`WaveTheme.EventBossGrade`). `BountyManager.SummonEventBoss` 로 소환하고 **현상금이 아니라서** 잡아도 등급 보상·다음 등급 해금이 없다.
  체력바에 이름 "보스전" 과 남은 시간 게이지(30초)가 뜬다. 시간이 지나도 보스는 남아 벽을 때린다(현상금과 같다).
- 상단 현황의 보상 아이콘: 행운 / 보스전 / 회복 / 다이스.
- 한 바퀴의 나머지는 그대로다: 3·6·9 현상금 도전, 5 자리/영혼(광고로 둘 다), 10 보스.

**재화 연출.** 이벤트가 마석·SP 를 주면 현상금·영혼 보너스와 같은 **날아가는 연출**을 쓴다(`SoulBonusManager.FlyEnhanceStone` / `FlySummonPoint` — 마석·SP 둘 다 먼저 `HoldStone` / `HoldSp` 로 쥐어 울타리 위 보유량 칸에 닿을 때 숫자가 오른다 — `IngameHudArtPort.md`).
출발 자리는 고른 버튼(`UIChoicePopup.LastChosenScreen`), 보스전은 보스가 쓰러진 자리다. 행운 주사위 굴림은 기존 결과 창이 같은 연출을 한다.

## 이벤트 17종과 판마다 무작위 배치 (2026-10-27 개정)

이벤트 자리(한 바퀴의 1·2·4·7·8웨이브 뒤)에는 **판이 시작될 때 한 번 섞어 정한** 이벤트가 나온다(`WaveEventPlan`). 20웨이브 판은 자리가 10곳이고 이벤트가 17종이라
**한 판 안에서 같은 이벤트가 겹치지 않는다**(자리가 더 많은 긴 스테이지는 다 쓴 뒤 다시 섞는다). 상단 현황의 보상 아이콘은 이 계획을 그대로 보여 준다(되돌려도 같다).
위의 "첫 바퀴 / 둘째 바퀴" 표는 계획이 없을 때(테스트·폴백)의 고정 배치다.

| 이벤트 | 고르는 것 |
|---|---|
| 영혼 보너스 | 기존 창(SP / 마석) |
| 행운 주사위 | 마석 5~15개 굴림 / 50 SP |
| 보스전 | 마석 10개 받고 지나가기 / 30초 안에 보스를 잡고 마석 20개 |
| 벽 회복 | 벽 10% 회복 / 50 SP |
| **다이스 선물** | 기본 다이스(노멀·파이어·아이스·썬더·독) **2성 중 무작위 둘** 중 하나 — 같은 등급대에서 아무거나 |
| **특수 다이스 선물** | 레어(허리케인·스턴·아머브레이크·윈드·타임) **중 무작위 둘** 중 하나 |
| SP 도박 | 50 SP 확정 / 50% 로 125 SP |
| 마석 도박 | 마석 6개 확정 / 40% 로 18개 |
| 소환권 | 무료 소환 3회 / 50 SP |
| 확률업 | 확률업 +1레벨(무료, 최고 레벨이면 못 고름) / 50 SP |
| 벽 강화 | 벽 최대 체력 +15%(그만큼 회복) / 벽 25% 회복 |
| 환전소 | 50 SP → 마석 6개(SP 모자라면 못 고름) / 지나가기 |
| 공격 속도 | 다음 웨이브 공격 속도 +30% / 50 SP |
| 슬로우 | 다음 웨이브 몬스터 이동 -30% / 마석 6개 |
| 약화 | 다음 웨이브 몬스터 체력 -25% / 50 SP |
| 위험한 거래 | 다음 웨이브 몬스터 체력 +30% 를 받고 마석 15개 / 지나가기 |
| 떠돌이 상인 | SP 35 / 마석 7개 / 벽 7% 회복 (3지선다) |

"다음 웨이브" 효과는 `WaveBuffs`(Core, 정적)가 든다 — 다이스 쿨타임(`DiceMetaDataProvider.GetCooldown`), 일반 몬스터 체력·이동속도(`MonsterSpawner.SpawnRegularMonster`)에 곱해지고,
그 웨이브가 끝나 다음 이벤트가 시작될 때 걷힌다. 판이 시작될 때·씬이 내려갈 때·되돌릴 때도 비운다. 숫자는 `WaveThemeFlow` 의 상수와 `WaveBuffs` 에서 바꾼다.
