# 웨이브 테마 (1스테이지 시험)

> 상태: **구현됨(2026-10-27, 1스테이지만).** 코드 `OJ.Core.WaveTheme` · `OJ.Hunting.WaveThemeFlow` · `WaveThemeUi` · `WaveThemeLayout`, 스위치 `StageData.waveTheme`.
> 측정과 수치는 `Docs/StageBalance.md` "1스테이지 30웨이브 · 웨이브 테마".

10웨이브가 한 바퀴이고 같은 패턴을 30웨이브까지 되풀이한다. 웨이브가 끝나면 **유저가 보상을 고른 뒤** 다음 웨이브가 열린다.

| 웨이브(한 바퀴 안) | 전투 | 끝난 뒤 |
|---|---|---|
| 1 · 2 · 4 · 7 · 8 | 물량전 | **영혼 보너스** 선택 창(기존 창: SP / 마석) — 닫아도 고를 때까지 다시 뜬다 |
| 3 · 6 · 9 | 물량전 | **현상금 도전할래요?** (도전 / 패스). 도전하면 기존 현상금 선택 창 → 기존 경고 연출 → 잡을 때까지 → 다음 웨이브 |
| 5 | 물량전 | **자리 +4칸 / 영혼 보너스** 중 하나. **광고를 보면 둘 다**(스테이지당 2번) |
| 10 | **보스 한 마리, 60초 안에** | **자리 +4칸 그리고 영혼 보너스** (고르는 것이 아니라 둘 다) |

- 보스를 60초 안에 못 잡으면 벽이 무너진 것으로 친다(되돌리기 제안 포함). 제한 시간은 게임 시간이라 배속을 따른다.
- 광고: `IRewardedAdService` 가 있으면 그것을 쓰고, 없으면(에디터) 바로 성공으로 친다. 광고 버튼은 실제 서비스가 없고 에디터도 아니면 안 뜬다.
- 자리 +4: `UIBoard.GrantFreeSlots` — 잠긴 자리를 앞에서부터 SP 없이 연다(탑에 막힌 칸은 건드리지 않는다).

## 화면

| 요소 | 내용 |
|---|---|
| 상단 웨이브 현황 | 동그라미 안에 웨이브 번호, 아래에 **그 웨이브가 끝날 때의 보상 아이콘**. 5웨이브씩 한 쪽으로 보여 주고 "…" 뒤에 마지막 웨이브. 10의 배수(보스)는 빨간 동그라미, 지금 웨이브는 노란 고리 |
| 웨이브 시작 | 가운데에 "N웨이브 Start"(보스는 "BOSS!") |
| 보스·현상금 체력바 | 상단 현황 아래. 보스는 그 아래에 남은 시간(10초 이하 빨강) |
| 하단 | 현상금·영혼 보너스 버튼 없음(선택 창으로만). 행운 주사위 임시로 끔. 강화 버튼은 왼쪽 아래로, 확률업 버튼은 1.3배. **보드 8칸 × 3줄 = 24칸**(옛 강화 버튼 자리를 보드로) |
| 선택 창 | 딤 + 가운데 창. 다이얼로그 캔버스 위에 올려 기여도 패널 같은 것이 비치지 않는다 |

## 주의
- 화면 요소는 전부 코드로 만든다(씬·프리팹 YAML 을 손대지 않는다). 중첩 캔버스는 **오브젝트의 레이어로 카메라에 걸러지므로** 만든 오브젝트의 레이어를 부모와 맞춘다(`WaveThemeUi.Rect`).
- 한 줄 칸 수는 `UIBoard.ConfigureColumns(8)`(이름과 달리 `rows` 가 한 줄의 칸 수다).
- 옛 영혼 보너스(처치 수가 차면 저금통 버튼)는 이 스테이지에서 쓰지 않는다(`SoulBonusManager.OfferNow` 로 웨이브 끝마다 제안).
- 값은 사람이 해 보고 정한다: 보스 체력 배수 `bossWaveHpFactors`(1 / 3.5 / 1.5), 중반 램프 `hpRampMultiplier`(3.8), 다이스 쿨타임 `BalanceProfile.CooldownMultiplier`(0.6).
