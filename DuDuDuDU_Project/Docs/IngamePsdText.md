# 인게임 글자 — PSD 기준 정리

2026-10-01. `Art/0PSD/인게임관련.psd` 의 글자 레이어(폰트·크기·색·외곽선 효과)를 `psd-tools` 로 읽어
인게임 글자와 대조하고 다른 것을 맞췄다. 현상금·경고 띠는 `WantedUIArtPort.md` 에서 먼저 맞췄다.

**도구**: 메뉴 `OJ/개발/인게임 UI/PSD 글자 맞추기` → `IngamePsdTextApplier`. 대응표가 코드 안에 있고,
두 번 돌려도 바뀌는 것이 없다(확인함: 바꿈 0 / 그대로 21). PSD 가 바뀌면 표를 고치고 다시 돌린다.

## 폰트는 BM HANNA

PSD 의 인게임 글자는 거의 전부 NotoSansKR-Black 이지만 **이 게임의 폰트는 BM HANNA 다**(2026-10-01 결정).
한 번 Noto 로 바꿨다가 되돌렸다. PSD 에서는 크기·색·외곽선만 가져온다.

## 결과

| 어디 | 무엇이 바뀌었나 |
|---|---|
| 전투 HUD (WAVE·50/60·x2·Play Wave·시작·10 / 1,000·뽑기·강화) | 없음 — 크기·색이 이미 PSD 와 같다 |

## 안 한 것

- **조합** 관련 그룹(조합설명·그룹 8·그룹 9) — 조합 기능은 게임에서 사라졌다. 이식 대상 아님
- **인게임내재화얻을때**(+100 x3), **보상** 그룹 제목 — 대응하는 게임 UI 를 못 찾았다
- PSD 에 레이어가 없는 글자(다이스·피해 숫자·유물·확인 창 등)는 그대로
