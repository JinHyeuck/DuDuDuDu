| 무엇 | 어디 |

| 강화 팝업 조립 | `Assets/Scripts/Equipment/UIEquipmentConfirmDialog.cs` `Build` (PSD `장비장착관련.psd` 그룹 `강화하기팝업` bbox 를 그대로 옮겼다) |

| 새 리소스 | `Resources/Art/Ingame/Big_Btn_Red.png` (`Art/Mail/` 에서, 초록 버튼과 같은 임포트 설정) |

## 결정표

| 항목 | 적용 | 근거·상태 |
|---|---|---|
| 팝업이 로비 윗 재화 띠·아래 탭 바보다 위 | 열 때 루트 캔버스 맨 끝 자식으로 옮기고 닫을 때 제자리로 | 중첩 캔버스로 순서를 올리면 `UIPopupRoot`(합성 창)와 순서가 같아질 수 있다 · 확정 |
| 보석 격자 | 이 부위 보석만, **종류별 한 칸 + 개수(xN)** | 시안의 x1 표기 · 예전은 낱개마다 한 칸 |
| 보석 누름 | 미니팝업: 격자에서 → "장착"(빈 칸 없으면 "빈 칸 없음"으로 잠금), 장착 줄에서 → "해제" | 시안 Prs 레이아웃 · 줄 오른쪽 해제 버튼도 그대로 동작 |
| 미니팝업 자물쇠 원 (677,1113) | 넣지 않음 | 대응 기능(보석 잠금)이 없다 · 확인 필요 |
| 줄 효과 이름 | `BuildEffectText` 를 " +"/" -" 에서 나눔. 효과가 여럿이면 줄에는 첫 효과만 | 시안 "전체 공격력 / +4%" · 대상 표기는 기존 그대로(`[Normal] 공격력`) |
| 등급 글자색 | 칸 프레임 색에 맞춤(노멀=#00B4FF …) | 시안 "레어" 파랑 1건뿐 · 추정 |
