## 결정

| 항목 | 적용 | 근거 |
|---|---|---|
| 보유량 칸 자리 | **시안 자리** — 통나무 아래 · HP 바 위(가운데 y 1173) | 처음엔 도우미 줄(＋ 6칸)이 그 자리를 차지해 울타리 위로 올렸다(사용자 선택). 도우미 줄을 지운 뒤 사용자 지시로 시안 자리로 되돌렸다 |
| 판 불투명도 | `Merge_Bg` 를 두 겹 깔아 가운데 알파 62% → 86% | 한 겹이면 뒤가 비친다. 시안 레이어 불투명도는 255 |
| 세로 앵커 | 화면 아래에서의 거리(보유량 칸 · HP 바 · 배속 버튼) | 전투는 아래 끝을 붙인 채 위쪽 시야를 늘린다 — 22:9 에서도 울타리에 붙어 있다 |
| 재화 연출 | SP·마석 모두 **보유량 칸으로 날아가고, 닿을 때 칸 숫자가 오른다** | 사용자 지시. SP 도 마석처럼 `HoldSp` → 지급 → 닿을 때 `ReleaseSp` |
| 모자람 표시 | SP 가 모자란 채 소환을 누르면 SP 칸이 흔들린다(마석 칸과 같은 연출) | 소환 버튼에서 보유량이 빠졌으니 무엇이 모자란지 칸이 말한다 |
| 기여도 패널 높이 | 윗선을 **시안(y 153)이 아니라 예전 높이(y 250)** 에 둔다 | 몬스터를 쏘기 시작하는 교전선(`EngageLine`)이 이 윗선을 따른다 — 시안대로 올리면 교전선이 100px 올라가 밸런스가 바뀐다. 시안 높이는 웨이브 이벤트 트랙과도 겹친다 |
| 기여도 막대 색 | 전부 초록 `78fe04`(시안) | 예전엔 다이스 색. 어느 다이스인지는 아이콘이 말한다 |
| 기여도 접기 표시 | 흰 막대(그림) | 예전 "×" 글자는 BM HANNA 에 없어 빈칸이었다 |
| 상세 창 속성 아이콘 | 시안에 없지만 다이스 아이콘 오른쪽 아래 작은 배지로 남김 | 빼면 전투 중 속성을 볼 곳이 없다 |
| 도우미 줄(`Helper`) | **씬에서 지움** (사용자 지시 2026-10-27) | 울타리 아래 ＋ 6칸. 스크립트·직렬화 참조가 하나도 없는 그림뿐이었다(지우기 전에 확인함) |
| HP 바(`Well`) | 시안 자리 — 화면 아래에서 668(가운데 y 1252) | 도우미 줄을 지우며 한때 730.6 으로 올렸으나 시안과 달라 되돌렸다 |
| SP 모자람 표시 | 소환 버튼 비용 · 확률업 비용 칩 숫자가 붉다(`UIDiceSummonSystem.LackingSpColor`) | 사용자 지시 |
| 확률업 버튼 크기 | 1스테이지 시험 판에서도 키우지 않는다 | 예전 1.3배는 글자 버튼이 작다는 평 때문이었다. 아이콘 버튼은 이미 크고, 키우면 보드 아래 칸을 덮는다 |
| 상세 창 판 | **불투명** — `Merge_Bg` 세 겹(가운데 95%), 정보 상자 불투명 | 한때 반투명(158)으로 했다가 글자가 안 읽혀 되돌렸다(사용자 지시). 두 겹(86%)이면 밑의 HP 바가 비친다 |
| 상세 창 진화 · 교환 자리 | 시안과 **서로 바꿈** — 교환 왼쪽, 진화 오른쪽 | 사용자 지시 |
| 상세 창 버튼 막기 | 진화 · 교환은 **늘 누를 수 있다.** 마석이 모자라면 판 위 보유 마석 칸이 흔들리고(숫자 붉게), 성급이 모자라면 "머지해서 3성을 만들어 주세요", 미보유·웨이브 중이면 그 이유를 토스트로 1.6초 | 사용자 지시. 회색 버튼은 왜 안 되는지를 말하지 않는다 |
| 상세 창 보유 마석 | 판 위 오른쪽에 마석 칸(보이는 210x64, 30pt) | 사용자 지시. 이 창이 울타리 위 보유량 칸을 덮어서, 진화·교환 비용과 견줄 숫자가 없어진다 |
| 상세 창 밑 보유량 칸 | 판에 **덮이는** SP·마석 칸은 창이 열린 동안 끈다 | 판이 반투명이라 밑 칸의 아이콘·숫자가 판 글자와 겹쳐 비쳤다. 꺼도 RectTransform 은 남아 재화 연출 목적지는 그대로 |
| 상세 창 안내 문구 | "4성부터 진화할 수 있습니다 (현재 1성)" | 예전 "★4" 의 ★ 가 BM HANNA 에서 빈칸이었다 |
