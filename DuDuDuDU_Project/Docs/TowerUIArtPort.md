## 사람이 할 일

- **9슬라이스 테두리 다듬기** — 아래 11장은 픽셀에서 계산한 대략값이다. Sprite Editor 에서 고치면 프리팹을 다시 굽지 않아도 반영된다.
  `Btn_PurpleGray(10,12,10,12)`, `Infinity_Popup_Bg_Dark/Light/Red/Selcet`·`Number_Mission/Normal/Special(9,9,9,10)`,
  `Skill_Selcet_Bg_Normal/Prs(11)`, `Skill_Selcet_Nonel(13)` — (왼,아래,오른,위)
- **굽기와 손 수정의 경계** — `UI 프리팹 굽기` 는 프리팹을 **통째로 새로 만든다.** 프리팹을 손으로 고친 뒤에는 이 메뉴를
  돌리지 말 것(고친 것이 사라진다). 결과 화면 프리팹이 이미 그런 상태다 — 저장소 판에 코드가 만들지 않는 `RewardRoot` 가
  있어서, 이번에도 결과 화면은 다시 구운 것을 버리고 저장소 판을 유지했다.

## 미결 질문

1. 시안에 없어서 뺀 기존 기능 — 편성의 **"추천 편성" 버튼**, 층 선택의 **최고 기록**과 **해금 목표 배너**(다음 해금 다이스·구간 보상). 코드는 남아 있고 프리팹에서만 빠졌다. 첫 도전은 여전히 추천 편성으로 자동으로 채워진다.
2. 편성 제목 "다이아 편성" 이 의도인가.
3. 층 카드 보상 칸의 우선순위(위 결정표).
